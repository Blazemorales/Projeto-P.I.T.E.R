# Requisitos - Anotações

Este material contém anotações manuscritas sobre o processo de levantamento e análise de requisitos de software.

## Conteúdo Principal

O documento apresenta diagramas e fluxos sobre:

### 1. Como fazer um balanço
- Como o client explicou
- Como o Scrum Master entendeu
- Como o analista projetou
- Entrevista
- Como o programador construiu
- Como o consultor descreveu
- Como foi documentado

### 2. Uso Inadequado de Instalação
- Como o client quer
- Monitoração usando callbacks

### 3. Fluxo de Requisitos

O documento apresenta um fluxo sequencial mostrando:

- Conhecimento do Requisito
- Identificação dos stakeholders
- Coleção dos Requisitos
- Análise dos Requisitos coletados
- Especificação dos Requisitos do Sistema
- Gerenciamento dos Requisitos de Software

## Observações

Este material é complementar aos outros documentos de requisitos disponíveis e ilustra visualmente os principais conceitos e processos envolvidos na engenharia de requisitos.
